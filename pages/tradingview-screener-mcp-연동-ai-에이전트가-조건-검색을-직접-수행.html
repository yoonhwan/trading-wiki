TradingView Screener MCP 연동 — AI 에이전트가 조건 검색을 직접 수행

원본: https://www.threads.com/@junhao_321/post/DXtJ8hrkwDJ
작성자: @junhao_321 (Threads, 1시간 전)

한 줄 요약

TradingView 스크리너를 AI 에이전트에 붙여서, *RSI·시가총액·시장 조건 같은 필터를 자연어로 지시하고 결과를 직접 표로 뽑아내는* MCP 연동 흐름이 등장했다.

스레드 핵심 포인트

  • “좋은 MCP 발견”으로 소개
  • TradingView의 *스크리닝/쿼리 기능*을 AI 에이전트에 연결 가능하다고 설명
  • 예시 프롬프트:

    • - “지금 미국 주식 중에서 RSI가 30 이하이고 시가총액이 10억 달러 넘는 종목들 찾아서 표로 정리해 줘”

  • 작성자 코멘트상 내부적으로 *Pine Script를 쓰는 것 같아 보인다*고 했지만,

    • 이 부분은 스레드 작성자의 추정이므로 *추가 검증 필요*

  • 연결 대상으로 GitHub deepentropy/tvscreener 저장소를 첨부

공식 저장소 기준 팩트 체크

  • 프로젝트: deepentropy/tvscreener
  • 정식 설명: *TradingView Screener API: simple Python library to retrieve data from TradingView Screener*
  • 성격: *비공식 서드파티 라이브러리* (TradingView 공식/제휴 아님)
  • 지원 자산군:

    • - Stock

    - Crypto

    - Forex

    - Bond

    - Futures

    - Coin

  • 필드 수: *13,000+ fields*
  • 결과 형식: *Pandas DataFrame*

MCP 관련 팩트

README 기준 v0.2.0에서 *MCP Server Integration*이 추가됨.

제공 도구 예시

  • discover_fields — 키워드 기반 필드 탐색
  • custom_query — 자유 쿼리
  • search_stocks / search_crypto / search_forex — 자산별 간편 검색
  • get_top_movers — 급등/급락 종목

설치/실행 예시

  • pip install tvscreener[mcp]
  • tvscreener-mcp
  • Claude Code 등록 예시도 README에 포함됨

왜 흥미로운가

  • 트레이딩뷰 웹 UI를 사람이 직접 만지는 대신,

    • *자연어 → 조건식 → 스크리닝 결과* 흐름으로 바꿀 수 있음

  • 13,000+ 필드와 여러 자산군 덕분에,

    • 단순 종목 검색이 아니라 *멀티마켓 퀀트 스크리닝 보조도구*로 확장 가능

  • 결과를 DataFrame으로 받아오므로,

    • 후처리·랭킹·시각화·리포트 자동화와 연결하기 좋음

주의할 점

  • *TradingView 공식 API가 아니라 비공식 라이브러리*라서 안정성·약관·장기 호환성은 별도 검토 필요
  • 스레드 본문에 나온 *Pine Script 내부 사용 여부*는 공식 README에서 바로 확인되진 않았음
  • 실시간 자동 갱신/빈번한 호출은 레이트리밋이나 정책 이슈를 확인하고 써야 안전함

자비스 관점 메모

  • yoonhwan 오빠 트레이딩 시스템 쪽에서 바로 떠오르는 활용은:

    • - 미국 주식/암호화폐 *조건 탐색 봇*

    - 섹터/시총/오실레이터 기준 *프리마켓 스캔 리포트*

    - Bond/Futures/Coin 포함 *멀티자산 관측용 에이전트*

  • 특히 OpenClaw + MCP 조합이면,

    • “조건 말하기 → 표 생성 → 요약 브리핑”까지 한 번에 이어붙이기 좋음
