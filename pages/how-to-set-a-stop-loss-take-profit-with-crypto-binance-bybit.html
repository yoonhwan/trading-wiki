How to Set a Stop Loss & Take Profit with Crypto (Binance, Bybit)

🎥 원본: https://youtu.be/g1TQpE6Y-Pw

📋 요약

  • 스탑로스·익절 주문의 작동 원리와 Bybit/Binance에서 단계별 설정 방법
  • 조건부 주문(Conditional Order) 개념 — 특정 가격 도달 시에만 주문 실행
  • SL 위치 선정 3가지 전략: 퍼센트법 / ATR법 / 지지저항법
  • 트레일링 스탑 주문 — 수익 보호용 동적 손절
  • 스팟 시장에서 TP와 SL을 동시에 걸 수 없는 이유

🗂️ 아웃라인

1. **TP/SL의 본질** — 둘 다 동일한 매도 주문, 가격이 익절/손절을 결정

2. **조건부 주문 설정** (Bybit 기준) — 트리거 가격 + 주문 유형 선택

3. **리밋 vs 시장가** — SL에는 시장가 또는 트리거보다 낮은 리밋 권장

4. **SL 위치 전략 3가지**

- 퍼센트법

- ATR (Average True Range)법

- 지지/저항선법

5. **트레일링 스탑** — 활성화 가격 + 콜백 비율

6. **스팟 시장 주의사항** — TP+SL 동시 설정 불가 이유

💡 키포인트

조건부 주문 개념

  • **리밋 주문 ≠ 스탑 주문**: 리밋 매도는 현재가 이하 즉시 체결 → SL 용도 불가
  • **조건부 주문**: "가격이 X에 도달하면 그때 주문 실행" (if→then 구조)
  • 스팟 익절은 리밋 주문만으로도 가능 (현재가 위 리밋 매도)

SL 위치 선정 3가지 전략

| 방법 | 설명 | 장점 | 단점 |

|------|------|------|------|

| **퍼센트법** | 진입가 기준 -10% 등 단순 % 설정 | 계산 간단 | 시장 맥락 무시 |

| **ATR법** | 일평균 변동폭(ATR) 기준 여유분 추가 | 현재 변동성 반영 | 지표 필요 |

| **지지/저항선법** | 주요 S/R 레벨 아래에 SL 배치 | 시장 구조 기반 | 분석 필요 |

ATR 활용 예시

  • BTC ATR ≈ $600/일 → 진입가 $20,000 기준 SL = $19,000 ($1,000 여유)
  • ATR의 1.5~2배 정도 여유를 주면 노이즈에 의한 허위 손절 감소

트레일링 스탑

  • **콜백 비율**: 현재가에서 몇 % 아래에 매도 주문 유지
  • 가격 상승 시 → 트레일링 스탑도 같은 % 따라 올라감
  • 가격 하락 시 → 스탑 고정, 해당 가격 도달 시 즉시 청산
  • **활성화 가격**: 현재가보다 높게 설정해야 롱 익절용으로 작동

⚠️ 스팟 시장 TP+SL 동시 설정 불가

  • 스팟은 실물 자산 정산 → SL 주문에 자산이 묶임
  • 자산이 묶인 상태에서 TP 주문 추가 불가 (이중 약정)
  • **해결책**: 선물 마켓 사용 또는 TP/SL 중 하나만 설정

📝 전사본 (핵심 발췌)

"We don't want to use a limit order for a stop loss. It's not going to work because if we tell the system using a limit order, sell BTC with a limit of 96 and the price is trading at 98, it is going to immediately sell."
"If the price moves up again... this trailing stop will move up the exact same amount. It will always be 2% away on the upside. As soon as the price starts moving back down again, this trailing stop order will not move down."
"If you put a stop loss order in at 96... you now have an IOU for that order because this is taking your actual assets right here and tying them up into a sell order."
