PostHog — 분석 도구 10개를 하나로 합친 오픈소스

원본: https://www.threads.com/@hermes_agent_kr/post/DXmc_pgk5Eo
작성자: @hermes_agent_kr (Threads, 2일 전)

한 줄 요약

GA + Amplitude + LaunchDarkly + Sentry를 단일 플랫폼으로 통합한 **오픈소스 제품 분석 스택**. ClickHouse 기반으로 수십억 이벤트 실시간 처리, MIT 라이선스, 셀프호스팅 가능.

핵심 키포인트

  • **GitHub 33.3K 스타**, MIT 라이선스 — 진정한 오픈소스
  • **10개 분석 도구 통합**: 제품 분석 / 세션 리플레이 / 피처 플래그 / A/B 테스트 / 에러 추적 / 데이터 웨어하우스
  • **기술 스택**: Python + ClickHouse + TypeScript
  • **무료 플랜**: 월 100만 이벤트 + 5천 세션 리플레이
  • **셀프호스팅**: Docker 한 줄로 띄움
  • **Y Combinator 출신**, 기업가치 **$700M+**
  • **투명 운영 철학**: 가격·로드맵·내부 OKR 모두 공개

대체 가능한 SaaS

| 카테고리 | 기존 도구 | PostHog 대응 모듈 |

|---|---|---|

| 제품 분석 | Google Analytics, Amplitude, Mixpanel | Product Analytics |

| 세션 리플레이 | Hotjar, FullStory | Session Replay |

| 피처 플래그 | LaunchDarkly, Split.io | Feature Flags |

| A/B 테스트 | Optimizely | Experiments |

| 에러 추적 | Sentry, Rollbar | Error Tracking |

| 데이터 웨어하우스 | Segment + Snowflake | Data Warehouse |

왜 주목할 만한가

  • 분산된 분석 SaaS 비용을 단일 스택으로 압축 → **TCO 대폭 절감**
  • ClickHouse 기반이라 자체 호스팅에서도 **수십억 이벤트** 처리 가능
  • 데이터를 자체 인프라에 두면서도 SaaS급 UX 확보 → **GDPR/PIPA 친화적**
  • 오픈소스 + 투명 운영 → 락인 리스크 낮음

자비스 활용 후보

  • BaseAgent / 트레이딩 시스템의 사용자 분석 백엔드 후보 검토
  • AI Feature Pack 텔레메트리에 self-hosted PostHog 도입 시 비용·프라이버시 동시 해결
  • bond-escape 리포트 시스템에 세션 리플레이 붙이면 사용 패턴 추적 가능

첨부 이미지 (6장 요약)

1. PostHog 올인원 제품 분석 플랫폼 인트로

2. 프로젝트 기본 스펙 (스타 수, 라이선스, 기업가치)

3. 통합된 10가지 도구 비교

4. 핵심 기능 상세 (Analytics / Replay / Flags / Experiments / Errors / DW)

5. 기술 스택 (Python + ClickHouse + TypeScript)

6. 도입 사례 + 투명 운영 철학
