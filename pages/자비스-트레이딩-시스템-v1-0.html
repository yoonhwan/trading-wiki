자비스 트레이딩 시스템 v1.0

**에이전트 + 인간의 반자동 학습형 크립토 트레이딩 시스템**
Created: 2026-03-05 | Channel: #trading-auto

---

🎯 시스템 개요

**목표**: 자비스와 yoonhwan 오빠가 함께 성장하는 트레이딩 시스템

  • 에이전트가 조건·아이디어를 제안 → 오빠가 동의하면 D.Terminal에서 실행
  • 매 거래마다 기록 → 패턴 분석 → rules.md 진화 → 더 나은 판단
  • 시드: 10만원 (공격형, 검증 후 증가)

---

🤖 에이전트 역할 (3단계)

Before Trade — 진입 전 분석

1. 현재 시장 상황 요약 (추세/박스, 변동성, 주요 지지·저항)

2. 행동 제안: 진입 / 추가진입 / 관망 / 청산 중 1개 + 이유

3. 진입 추천 시 D.Terminal 명령까지 제안:

   market buy BTCUSDT 0.5 sl=95000 tp=105000

**응답 형식:**

[행동] 관망 (또는 진입/청산)
[이유] BTC 일봉 기준 98,500 저항대 테스트 중. 돌파 확인 전 진입 자제.
[다음 체크] 98,500 돌파 + 거래량 급증 시 진입 재검토.

After Trade — 거래 후 분석

1. PnL, 최대 드로다운, 계획 대비 이탈 여부

2. 배운 점 1~3가지 제안

3. 저널 파일 저장용 텍스트 생성 (바로 붙여넣기 가능)

Periodic — 주기적 성과 분석 (1일/1주)

1. 누적 기록 분석 (수익/손실 조건, SL/TP 적절성)

2. 시간대·변동성·시장 구조별 성과 차이 요약

3. 다음 주 바꿔볼 규칙 1~3개 제안 → rules.md 업데이트

| 손실 | ✅ 일치 | 전략 문제 | 해당 조건 재검토/제거 |

**핵심**: 실수할 때마다 rules.md에 교훈 추가 → 500줄짜리 교훈집으로 성장 (Larry가 그랬듯)

📏 초기 리스크 관리 규칙 (v1.0)

1. **최대 손실**: 전체 시드 10만원의 5% = 5,000원/거래

2. **SL 필수**: 모든 진입 시 SL 동시 설정 (D.Terminal sl= 파라미터)

3. **레버리지**: 초기 1~3x (검증 전까지 제한)

4. **거래 간격**: 이전 거래 결과 분석 후 다음 진입 (충동 방지)

5. **알림 시간**: 24/7 (코인 특성상 전 시간대 알림)

---

🔄 시스템 진화 규칙 (Compact 재정리)

  • **평가 주기**: 1주일마다 rules.md 검토
  • **규칙 추가**: 같은 실수 2회 이상 → rules.md에 영구 규칙 추가
  • **규칙 제거**: 3회 연속 상충 → 제거 검토
  • **문서 compact**: 규칙이 30개 초과 시 → 핵심 원칙으로 재정리
